# Guia de Contribuição

Obrigado por contribuir com a **RPUtilidades Store**!

## Como Contribuir

1. Faça o Fork do repositório.
2. Crie uma branch para sua modificação (`git checkout -b feature/minha-feature`).
3. Execute o linter antes de comitar:
   ```bash
   npm run lint
   ```
4. Teste a build de produção:
   ```bash
   npm run build
   ```
5. Envie as alterações e abra um Pull Request.
